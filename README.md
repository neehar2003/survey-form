# Survey Form

A responsive survey form built as part of the freeCodeCamp Responsive Web Design curriculum.

## Technologies Used

- HTML5

## Features

- User input form
- Name and email validation
- Age input
- Dropdown selection
- Radio buttons
- Checkboxes
- Comments textarea
- Responsive design

## Project

This project was created to practice HTML forms, form validation.
